# Telecom Website – Go Quality Networks

Frontend implementation of a professional telecom service provider website built for **Go Quality Networks**.

## Overview

This repository contains the source code for a telecom business website designed to present internet and network service offerings in a clear, structured, and user-friendly way. The project focuses on responsive design, clean layout, and performance-oriented frontend development.

The website is built to reflect a real-world ISP business, showcasing services, coverage information, and company details with a professional visual hierarchy.

## Features

- Responsive telecom business website
- Clear presentation of internet and network services
- Structured sections for services, coverage, and company information
- Clean and consistent UI using utility-first styling
- Mobile-friendly layout with optimized spacing
- Fast-loading static frontend

## Tech Stack

- React (Vite)
- Tailwind CSS
- JavaScript (ES6+)
- PostCSS
- Vercel for deployment

## What This Project Demonstrates

- Building real-world business websites
- Strong understanding of responsive UI design
- Clean frontend structure and styling consistency
- Practical use of Tailwind CSS in production layouts
- Experience deploying and maintaining live client-facing websites
